# Business Operations, CRM & Lead Generation Systems

This category is evidence-backed but intentionally narrow. A static contact form is not counted as a CRM.

## Lead and Contact Operations Console

Implemented source supports lead and contact records, lifecycle and review fields, deduplication, filters, pagination, detail views, summary counts, and CSV export. External integrations were not used as public proof, and this work is not described as a complete CRM.

**Demonstrates:** Python/FastAPI boundaries, SQLite persistence, repeat-safe record updates, operational status fields, and dashboard data flow.

**Verified technologies:** Python, FastAPI, SQLite, Next.js, React, TypeScript.

Deeper confidential implementation details are not included.

## CRM Interface and Data-Model Prototype

Implemented UI routes cover lead list, create, detail, company, and dashboard surfaces. Type definitions represent lifecycle states, assigned follow-up tasks, companies, contacts, deals, and pipeline stages. The dashboard contains demonstration values and no complete API route set was found, so this is labelled a prototype—not a working full CRM.

**Demonstrates:** TypeScript domain modelling and lifecycle-oriented interface design.

## Service-Business Operations Prototype

A separate service-business web application contains operational routes and reusable UI for a cleaning-service context. No automated tests were found and it was not run during verification, so it remains supporting source evidence only.
