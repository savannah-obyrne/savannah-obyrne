# Media Production Workflows

## Podcast Production Workspace

Two related private applications model episode, guest, and production work in Next.js/TypeScript with Prisma-backed relational structures. They demonstrate workflow decomposition and data modelling; evidence is based on source and manifest inspection rather than runtime screenshots.

## Local Content Production Studio

A local studio application presents media-production stages and local service boundaries. Supporting experience includes staged media workflows and local service integration; deeper confidential implementation details are not included.

## Creative Writing & Story System

A desktop/web writing application uses TypeScript, Python, Tauri, and relational models for projects, characters, scenes, and writing workflow. It is presented as supporting source evidence rather than runtime proof.
