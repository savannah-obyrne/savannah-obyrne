# Private Work, Public Proof

The underlying repositories remain private because they contain client work, business logic, and confidential implementation details. The portfolio uses real application screenshots, public-safe conceptual diagrams, exact verification results, and a few narrow code excerpts to show product-development work without exposing full repositories or private data.

I led product and workflow design, defined important business rules and data relationships, and used AI coding agents to assist with implementation. I reviewed the resulting changes and used automated checks, testing, and hands-on verification to identify problems and confirm important behaviour.
